Before you connect

Remote support instructions

  1. Contact Nana K IT Solutions Consult first and confirm the support session.
  2. Use only the download button on this official site.
  3. Run the approved support tool and share the session code only with the verified technician assisting you.
  4. Stay at the device during the session where practical and close sensitive documents.
  5. End the session when the requested support work is complete.
Never share: account passwords, MFA codes, recovery keys, or banking credentials.
