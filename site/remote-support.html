Before you connect

Remote support instructions

  1. Contact Nana K IT Solutions Consult first and confirm the support session.
  2. Use only the remote-support download link provided on this official domain.
  3. Download and run the approved support tool from the R2-backed link below.
  4. Share the session code only with the verified support technician assisting you.
  5. Stay at the device during the session where practical, and close sensitive personal documents.
  6. End the session when the requested support work is complete.
Never share: account passwords, MFA codes, recovery keys, or banking credentials with a support technician.
